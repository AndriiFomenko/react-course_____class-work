# 01 — Reusable Components

Навчальний проект для вивчення та відпрацювання концепції **перевикористовуваних компонентів (Reusable Components)** у React з використанням **TypeScript** та **Vite**.

---

## 🚀 Технологічний стек

- **React** `^19.2`
- **TypeScript** `~6.0`
- **Vite** `^8.2`
- **ESLint** & **Prettier**

---

## 📦 Встановлення та запуск

Всі команди виконуються через менеджер пакетів **Yarn** (або альтернативно через **npm**):

### 1. Перехід у директорію проекту
```bash
cd 01-reusable-component
```

### 2. Встановлення залежностей
```bash
yarn install
# або: npm install
```

### 3. Запуск dev-сервера
```bash
yarn dev
# або: npm run dev
```

### 4. Збірка для продакшену
```bash
yarn build
# або: npm run build
```

### 5. Перевірка коду (Linting)
```bash
yarn lint
# або: npm run lint
```

## 🎯 Цілі та завдання модуля

1. **Композиція компонентів**: розбиття інтерфейсу на незалежні, ізольовані блоки.
2. **Типізація пропсів (Props)**: передача даних у дочірні компоненти з суворою типізацією через TypeScript interfaces/types.
3. **Гнучкість та універсальність**: налаштування варіантів відображення (`variants`), розмірів (`sizes`), обробників подій (`onClick`) та підтримка `children`.
