# 05 — Children Props

Навчальний проект для вивчення та відпрацювання концепції **`children` пропсів** та **композиції компонентів (Component Composition)** у React з використанням **TypeScript** та **Vite**.

---

## 🚀 Технологічний стек

- **React** `^19.2`
- **TypeScript** `~6.0`
- **Vite** `^8.2`
- **ESLint** & **Prettier**

---

## 📦 Встановлення та запуск

Всі команди виконуються через менеджер пакетів **Yarn** (або альтернативно через **npm**):

### 1. Перехід у директорію проекту
```bash
cd 05-children-props
```

### 2. Встановлення залежностей
```bash
yarn install
# або: npm install
```

### 3. Запуск dev-сервера
```bash
yarn dev
# або: npm run dev
```

### 4. Збірка для продакшену
```bash
yarn build
# або: npm run build
```

### 5. Перевірка коду (Linting)
```bash
yarn lint
# або: npm run lint
```

## 🎯 Цілі та концепції модуля

1. **Проп `children`**: використання спеціального пропу `children` для передачі дочірніх елементів усередину компонента.
2. **Типізація з `React.ReactNode`**: коректне використання типу `React.ReactNode` у TypeScript для підтримки будь-якого вкладеного контенту (текст, числа, фрагменти, HTML-теги або інші React-компоненти).
3. **Гнучка вкладена розмітка**: можливість комбінувати іконки, емодзі та текст (наприклад, елементи `<span>`) всередині кнопки без зміни внутрішньої логіки самого компонента [Button](file:///d:/webProjects/LearningTemplates/_____class_____/react-course_____class-work/05-children-props/src/components/Button.tsx).
4. **Композиція інтерфейсу**: побудова гнучких та розширюваних UI-елементів за принципом відкритості до композиції.
